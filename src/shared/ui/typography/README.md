# Typography

Единый набор существующих текстовых стилей. Импорт: `@/shared/ui/typography`.
Компонент не требует `use client`, по умолчанию выводит `<p>` с вариантом `body`.
`as` выбирает HTML-тег независимо от оформления; атрибуты и `ref` типизированы
для выбранного тега (`dateTime` для `time`, `href` для `a` и т. д.).

## Шрифты и наследование

- **R** — Raleway, подключённый в `app/layout.tsx`: 400 (Regular), 500 (Medium),
  600 (SemiBold). Наследуется от `html` через `font-sans`.
- **F** — локальный FoglihtenNo06, 400 (Regular), `var(--font-foglihten)`.
  `category-title` и `directory-title` также сохраняют запасное семейство `serif`.
- Все начертания прямые (`normal`); курсив в исходном интерфейсе не используется.
  Существующий токен `--font-mono` не используется текстовыми элементами.
- Варианты сохраняют исходное наследование: если вес, семейство или интервал не
  заданы классами, они приходят от родителя. В таблицах показан результат в текущем
  интерфейсе при корневом размере 16px. Tailwind-размеры остаются в rem.
- Цвет, отступы, выравнивание, обрезка и оформление ссылок остаются у потребителей.
  Варианты не добавляют блоковые обёртки, отступы или клиентскую границу.

## Варианты

Стрелка означает переход на `mobile` (≥768px), если не указан другой breakpoint.
`tablet` = 991px; `desktop1250` = 1250px; `desktop1350` = 1350px;
`desktop1450` = 1450px. Значения line-height без единиц — множители размера.

| variant | Назначение | Шрифт / вес | Размер | line-height |
| --- | --- | --- | --- | --- |
| `body` | Обычный текст, вариант по умолчанию | R / наследуется (400) | 16px | 1.5 |
| `caption` | Мелкие подписи и номера мобильного меню | R / 400 | 12px | 4/3 |
| `small` | Подписи, статусы и описания поиска | R / 400 | 14px | 10/7 |
| `medium` | Выделение пустого результата; модификатор поля поиска | R / 500 | наследуется | наследуется |
| `heading-small` | Заголовок результата поиска | R / 600 | 16px | 1.5 |
| `heading-medium` | Заголовок группы результатов поиска | R / 600 | 20px | 1.4 |
| `section-title` | Заголовки секций главной страницы | F / 400 | clamp(24px, 3vw, 40px) | 1.25 |

Адаптивные размеры, перенесённые из CSS Modules без изменения:

| variant | <768px | ≥768px | Старший breakpoint |
| --- | --- | --- | --- |
| `hero-title` | clamp(26px, 5.8vw, 44px) | clamp(40px, 4.5vw, 54px) | ≥1250px: clamp(40px, 3.34vw, 64px) |
| `hero-description` | 12px | 16px | ≥1250px: clamp(14px, 1.05vw, 20px) |
| `directory-title` | clamp(24px, 6vw, 38px) | 48px | ≥1450px: clamp(48px, 3.34vw, 64px) |

`hero-title` и `hero-description` сохраняют `uppercase` и `white-space: pre-line`.
У заголовка баннера — `overflow-wrap: break-word`, у подзаголовка —
`letter-spacing: 0.07em`. `navigation` сохраняет `nowrap`, `directory-title`
включает его с 1450px. У остальных вариантов letter-spacing и регистр наследуются.

### Текст интерактивных элементов

`typographyVariants` экспортирует те же классы для `Button`, `Input`, `Link` и
компонентов Base UI. Они сохраняют собственную семантику и обработчики;
дополнительный `<span>` внутри кнопки или поля не нужен.

| variant | Назначение | Шрифт / вес | Размер | line-height |
| --- | --- | --- | --- | --- |
| `button` | Базовая кнопка | R / 500 | 14px | 10/7 |
| `button-pill` | Крупная кнопка | R / 600 | 16px | 1.5 |
| `button-xs` | Модификатор размера xs | R / наследуется | 12px | 4/3 |
| `button-sm` | Модификатор размера sm | R / наследуется | 0.8rem | наследуется от базовой кнопки |
| `button-login` | Кнопка входа | R / 600 | 14px | 10/7 |
| `button-responsive` | Модификатор кнопки «Все мероприятия» | R / наследуется (600) | 14 → 16px | 10/7 → 1.5 |
| `input` | Поле ввода | R / наследуется (400) | 16 → 14px | 1.5 → 10/7 |
| `search-trigger` | Поле открытия поиска | R / 500 | 12 → 14px | 4/3 → 10/7 |

`input` также сохраняет `file:text-sm file:font-medium` для кнопки выбора файла.
Модификаторы размеров не переопределяют вес основного варианта кнопки.

## Примеры

```tsx
import { Typography, typographyVariants } from "@/shared/ui/typography";

<Typography as="h2" variant="section-title" id="news-heading">
  Новости
</Typography>

<Typography variant="small" className="mt-2 text-muted-foreground">
  Найдено: 3
</Typography>

<Typography as="time" variant="date" dateTime="2026-09-09">
  9 сентября 2026
</Typography>

<Link href="/" className={typographyVariants["footer-link"]}>
  Реквизиты учреждения
</Link>
```

Выбирайте существующий вариант по назначению. `className` объединяется через
проектный `cn`; используйте его прежде всего для цвета и размещения. Адаптивные
параметры и семейства меняйте в общем варианте, а не копируйте в компоненты страниц.
CSS Modules для плавных размеров не следует переопределять конфликтующими
Tailwind-классами: `cn` не разрешает конфликты между CSS Modules и utilities.
Скрытые `sr-only` подписи диалогов и каруселей, а также декоративные SVG/спаны
остаются специализированными элементами и не требуют `Typography`.
